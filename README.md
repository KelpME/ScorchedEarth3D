# Scorched Earth 3D

A fan remake of the 1991 DOS classic **Scorched Earth** in the browser —
turn-based artillery on a destructible 3D voxel battlefield, built on Three.js.

This repo holds the **playable build** (self-contained: engine and
three.js are vendored under `vendor/`). Open `index.html` in a browser, or
serve the folder with any static file server:

```sh
python3 -m http.server 8080
# → http://localhost:8080
```

The engine platform lives in the **Hermes3JSForge** repo.
